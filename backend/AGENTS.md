# Skills

Store skills in:

skills/<skill-name>/

Each skill directory must contain:
- SKILL.md

Rules:
- Keep skills narrowly scoped.
- Prefer extending existing skills over creating overlapping ones.
- Avoid repository-specific assumptions unless required.
- Avoid vendor-specific features or commands.
- Keep skills reusable across repositories and agent systems.
- Use relative paths only.
- Do not store secrets, credentials, or local machine paths.
